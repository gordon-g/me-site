Trends

  1. The skill ecosystem enters supply-chain governance. NVIDIA defines "verified skills" with signatures, evaluation sets and benchmark reports; AAS spent the same day fixing missing release identity, skipped source verification and false-ready admissions. Medical skill libraries will be the first asked to produce this evidence.
  2. Coding agents compete on resources and handoff, not capability. jcode runs dozens of agents in little memory and turns cloud migration into a checklist; t3code moves the control plane to a phone; magpie puts model routing in the menu bar. All three answer the same question: once there are many agents, where is the human-machine boundary.
  3. Clinical AI starts falsifying itself with reader studies and regression baselines. The neonatal paper injects errors to measure human response; NotePilot tests its own checking layer on a 24×3 synthetic corpus. Both state their limits openly — closer to shipping than leaderboard chasing.
  4. The health data layer converges on self-hosting plus a standard exit. open-health-sync offers one dataset with four exits, HealtOS got import and rollback right first, quantified-self-mcp first fixed "listens on all interfaces by default". The order is always trust first, intelligence second.
  5. Three new landing spots in nutrition: specialist agents (carefold adds a dietitian navigator), explainable scoring (eat.me.at's recipe nutrition score), and supply-chain hygiene (SuperMealPlanner cleaning up a leaked intermediate certificate). "Photograph it and estimate calories" is no longer the only story.
  6. Medical infrastructure experiments with Rust. FHIR servers (hfs) are rebuilding query backends for memory footprint and concurrency rather than language preference — worth tracking quarterly.
