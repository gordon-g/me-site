本期精选（4 条，说明为什么值得关注）

1. deepseek-ai/deepseek-harness：模型厂亲自下场做"插件化 Agent 运行时"

https://github.com/deepseek-ai/deepseek-harness

DeepSeek 官方开源的 Agent Harness 提出核心理念 "Everything is a Plugin"（Cordis/DSH 插件体系），24 万 Star 的体量说明这不是实验品。值得关注的原因：前两期观察到"Skill/MCP 成为分发单位"是社区自发的生态演化，而这次是头部开源模型厂把插件化直接做成官方架构承诺——意味着 Agent 工具链正从"拼装玩具"进入"平台级基础设施"阶段。对你的 AI Coding 工作流而言，插件优先的 harness 意味着医疗/营养类技能（如医学技能库）未来可以更平滑地挂载到不同底座上。

2. mattpocock/skills：156k Star 证明"方法论 > 模型"

https://github.com/mattpocock/skills

一个纯 Shell 写的 .claude 目录技能包冲到 15.6 万 Star、还在以每天 +1000 的速度增长，没有框架、没有公司、没有融资。值得关注的原因：它瞄准编码 Agent 真正翻车的四个点——理解偏差、输出啰嗦、代码跑不起来、架构腐烂，分别对应 grill-with-docs、tdd、diagnosing-bugs、improve-codebase-architecture 等命令。瓶颈早已不在模型，而在工程判断力的封装。这套技能可直接 npx skills add mattpocock/skills 安装，是普通人"白嫖资深工程师工作流"成本最低的方式。

3. MedicalHarness：医疗 Agent 的分数，四分之一是 Harness 的功劳

https://github.com/REAL-Lab-NU/MedicalHarness

西北大学团队的受控实验（arXiv:2610.05778）：固定模型只换 Harness，发现 harness 及其与模型的交互解释了约 25% 的医疗任务结果方差，且没有任何一个 Harness 在所有模型和任务上通吃。值得关注的原因：这给前两期的观察（"医学 AI 焦点从答得对转向说得清"）补上了量化证据——今后看到任何"医疗 Agent 达到 XX 分"的宣传，都要先问一句"用的什么 Harness"。如果你在评估医疗/健康类 Agent 产品，这是最该读的一篇方法论文；同时也暗示医疗 Agent 优化的最大低成本杠杆可能在脚手架而非换模型。

4. 营养/健康数据层进入"统一平台 + 对话即 UI"第二阶段

https://github.com/akutishevsky/nutrition-mcp 、 https://github.com/the-momentum/open-wearables

上期观察到"健康数据 MCP 化集群"（十几个单点 MCP 服务器），本期出现两个标志性进化：① nutrition-mcp 用一个对话式 MCP 服务器替代整个 MyFitnessPal——记餐（支持拍照/条码）、目标、趋势全靠聊天完成，还能无缝导入四大主流饮食 App 的历史数据，迁移成本几乎归零；② open-wearables 从 Apple-Health-only 的脚本进化为自托管多品牌（Garmin/Polar/Whoop/Suunto）统一 API 平台。值得关注的原因：营养追踪类应用的用户粘性壁垒正在被"数据可携带性 + 对话式交互"瓦解，个人健康数据的主权（self-host、local-first）成为默认架构选择。这与你的营养/健康管理业务方向直接相关：值得评估把 nutrition-mcp 的导入器设计思路和数据模型作为自建系统的参考。

观察与趋势

  1. 技能库的"人格化"：mattpocock/skills、agency-agents、ponytail 共同说明——Agent 技能正在从"工具说明书"演化为"可安装的工程人格/方法论"，个人 .claude 目录成为新的技术资产形态。
  2. 决策模型成为新物种：vllm-sr Decision 3.0 与 Amazon Strands Decider 同期出现，"不生成 token、只输出选择+置信度"的模型层正在独立成型，Agent 的每一步路由可能由一个 2B 小模型完成，成本曲线将被重写。
  3. 医疗评测进入"三维时代"：模型 × Harness（MedicalHarness）× 时间（HAEnv 纵向合成病人）——单轮问答基准正在过时。
  4. 健康数据层收敛：十几个单点健康 MCP 正在合并为少数统一平台（open-wearables、mirobody）， nutrition-mcp 的"App 代替"叙事预示下一战场是迁移与数据主权。
