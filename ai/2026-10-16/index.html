五、今日精选：3-5 条最值得关注

① 医学 AI 技能库进入"千项规模"竞争——OpenClaw-Medical-Skills 与 scientific-agent-skills 同日上榜

  • 事件：FreedomIntelligence/OpenClaw-Medical-Skills 以 869 个医学 Agent Skill 成为目前体量最大的开源医学技能库，覆盖生物医学与临床研究全流程；同日 K-Dense-AI/scientific-agent-skills 以 177 个"已验证"技能 + 100+ 科学数据库冲上 GitHub Trending 单日 +1,091。
  • 为何值得关注：医学 AI 的竞争焦点正在从"训练一个医疗大模型"转向"把临床与科研流程编译成 Agent 可直接执行的技能"。技能库的价值在于可审计、可复用、可本地化；对医药、器械、健康管理类业务而言，这意味着不必自研底座模型，也能快速搭建合规可控的垂直能力。"已验证（validated）"这一表述尤其关键——它是医疗场景能否落地的分水岭。

② 端侧医疗数据脱敏：OpenMed 把 HIPAA 合规做成本地能力

  • 事件：maziyarpanahi/openmed 提供临床 NER 与 HIPAA PII 去标识化，100% 端侧运行（Apple MLX + Python），内置 2,200+ 医疗模型、21 种语言，数据不出内网；配套 73 个 Agent Skills 可让 Claude Code / Codex 直接生成脱敏管道。
  • 为何值得关注：医疗 AI 落地最大的拦路虎是数据合规，而非模型能力。把脱敏能力下沉到端侧设备，等于绕开了"数据上云"这一最大法务障碍，同时保持可编程（Skill 化）。这条路径对国内医院、体检机构、健康管理企业的私有化部署极具参考价值——注意其合规框架是 HIPAA，国内落地需对应《个人信息保护法》与《医疗卫生机构网络安全管理办法》重新映射。

③ 食品营养 AI 从"记录"走向"审计"：FoodTruth 用视觉模型拆穿包装话术

  • 事件：dasouvik122005/FoodTruth 用开源权重视觉模型（Gemma）同时读取包装正面宣称与背面配料表/营养表，自动识别三类问题：隐藏糖（如"无添加糖"却含 GI 110 的麦芽糊精）、"乳清蛋白撒粉式"虚假宣称（配料表排序在第 3 位之后）、以及违规疾病功效宣称，并给出 GI 风险、DIAAS 蛋白质量分级与合规引证。MIT 协议，含可商用路径（B2C 订阅 / 营养师席位 / B2B 标签预审 API）。
  • 为何值得关注：这是营养学约束 + 视觉模型 + 法规规则引擎的三层组合，落地形态清晰（超市货架扫码 2 秒出结论）。相比市面上"记录热量"的追踪器，它把 AI 用在"判断宣称真假"这一更高价值的位置，对健康管理、慢病干预、功能性食品营销合规都有直接业务价值。配套的 FoodYou 则代表了另一端——纯本地、无账号、隐私优先的营养追踪，两者合起来说明饮食类 AI 正在同时向"审计"和"隐私"两极分化。

④ GitHub 把 Copilot 从"选模型"改造成"编排模型"：HydraFusion Max 上线

  • 事件：GitHub 于 10-14 更新 Copilot 的 HydraFusion 多模型编排系统：新增 Max 档；模型池换为 Claude Opus 5.5 / GPT-6 Astra / GPT-6.1 Sol / GPT-6 Luna；推理强度按阶段分配（初稿 medium、评审 high）；Cascade 工作流新增"裁判"步骤，先判断初稿是否需要定向修复，再决定是否升级到更强模型；Critique 从"读文本摘要"改为直接检查工作区，并并行运行多个评审模型。
  • 为何值得关注：AI 编程助手的关键变量已经从"底座模型谁更强"转向"编排策略怎么分配算力"——先便宜草稿、再重点评审，这几乎复刻了成熟工程团队的真实协作方式。对团队的启示是：评估这类工具时要看"工作流策略"，而不只是模型版本号。需注意 GitHub 未公布新版基准数据，Max 的实际收益仍需在自有仓库上实测。

⑤ WiFi 变身健康传感器：RuView 用零画面方式做生命体征监测

  • 事件：ruvnet/RuView 把普通商用 WiFi 信号转为实时空间智能，实现呼吸/心率等生命体征监测与人员存在探测，完全不采集视频画面，当日 +197。
  • 为何值得关注：这是健康管理场景里少见的"隐私零成本"技术路线——在卧室、卫浴、养老院等摄像头天然不适配的空间，用已有的 WiFi 硬件即可实现连续体征感知。若与前三类技能库/数据层结合，可组成"感知 → 脱敏 → Agent 干预"的完整链路，对居家养老、睡眠管理、独居监护等业务想象空间较大；短板是精度与医疗级认证尚未明确。

六、趋势小结

  1. 技能（Skill）成为新的分发单位：无论是编程还是医学，生态竞争都从模型转向"技能包 + MCP 服务器"，医学侧已出现 869 项规模的技能库。
  2. 本地优先（Local-first）在医疗健康赛道成为默认选项：OpenMed、FoodYou、RuView 都在强调数据不出设备——合规压力正在重塑技术选型。
  3. 饮食类 AI 从"记录工具"升级为"判断工具"：GI / DIAAS / 合规引证这类确定性营养学规则，正被显式编码进审计引擎，而非交给模型自由生成。
  4. 开放权重仍在加速：Meta Muse Spark Open（816B）与阶跃 Step 5 Preview（600B）同日开放权重，且都明确面向长程 Agent 任务。
  5. 开源供给速度超过消费速度：当日 Trending 中 Agent 编排、技能库、上下文压缩类项目占绝对多数，选型与治理（安全、审计、上下文成本）正成为新的瓶颈。
